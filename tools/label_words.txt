# Subject vocabulary for the Image map's cluster labels.

# One term per line; `#` comments and blank lines are ignored. Terms are merged
# with the 365 Places365 scene categories (downloaded by
# build_label_vectors.py), deduped, and encoded into server/label_vectors.npz.
# Overlap with Places365 is fine and expected — it covers *scenes*, this covers
# what is in the frame.
#
# Editing this file changes nothing until you re-run:
#     .venv/bin/python tools/build_label_vectors.py
#
# Write terms as a photographer would describe the subject, not as a single
# abstract noun: each one is substituted into "a photo of a {}." and friends, so
# "cup of coffee" beats "coffee" and "snowy mountain peak" beats "peak".
